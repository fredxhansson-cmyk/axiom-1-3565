# Digital Måltidsplanerare för Växtbaserad Kost

Kort deploy-guide

## Installation

1. Klona repositoriet.
2. Installera beroenden med `npm install`.
3. Skapa en `.env`-fil baserat på `.env.example`.
4. Kör i utvecklingsläge med `npm run dev`.
5. Bygg produktionen med `npm run build` och starta med `npm run start`.

Se till att miljövariabler är korrekt inställda för att använda Stripe.
